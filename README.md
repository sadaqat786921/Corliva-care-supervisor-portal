# CORLIVA — Care Supervisor Portal

Clickable prototype of the Care Supervisor web portal for the CORLIVA home care platform. Same design system as the Agency Admin and Care Coordinator portals.

**Pages:** Sign in · My work · Visit approvals (+ full visit screen) · Care plans (+ full care plan screen) · Checks · Clients (+ full client screen) · Schedule · Today’s visits · Caregivers (+ profile) · Incidents (+ full incident screen) · Settings

```
npm install
npm run dev
```

Demo sign-in: any email and password, then security code 246810. See `AGENTS.md` for the design rules and every flow.
